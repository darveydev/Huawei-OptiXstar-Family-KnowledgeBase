## A 方案：纯桥接，弃用从网关

### 做法
1. V176-20 改成纯桥接，WAN 绑 VLAN 示例值（原文示例为 41） 到网口1
2. MT6000 WAN 口接网口1，PPPoE 拨号
3. 三个 K156-20 拔掉光纤，断电收纳

### 适用场景
- 家里本来就有网线到各房间，MT6000 + 若干 AP 足够覆盖
- 或者你已经有 Mesh 路由（同品牌多台）
- 或者光猫塞在弱电箱，K156-20 的 Wi-Fi 位置本来就不好

### 致命缺点
你花钱办的 FTTR 套餐，**三个从网关直接变废铁**；如果家里是靠光纤穿墙到房间的（没网线），方案 A 直接不成立。

### 什么时候该选它
只有一种情况：**你确定不要光猫的任何 Wi-Fi，且三个 K156-20 你无所谓**。

## B 方案：VLAN 单线复用（推荐）

### 原理
主网关桥接后当二层交换机，一条网线同时承载：
- **VLAN 示例值（原文示例为 41）（带 tag）**：宽带业务，给 MT6000 的 WAN 用
- **VLAN 1（不带 tag）**：内网，MT6000 的 LAN 和主网关的 LAN 侧互通

### 需要的东西
- V176-20 **超级管理员密码**（`CMCCAdmin` + 后台密码，或找装维师傅要）
- 宽带 **PPPoE 账号密码**
- 宽带 **VLAN ID**（移动常见 41，必须从原配置抄）
- MT6000（原生 OpenWrt 系，支持 802.1Q VLAN，无压力）

### 优点
- 一根网线搞定，弱电箱到客厅只走一条线也能实现
- 三个 K156-20 全保留，全屋光纤覆盖 + 无缝漫游照旧
- 公网 IP / NAT / 防火墙 / DDNS 全在 MT6000 手上，管一处就够

### 缺点
- 配置步骤多，改错会全家断网
- 移动后台有可能下发配置覆盖你的桥接设置（见风险章节）

## B-简 方案：双网线回灌（不折腾 VLAN）

### 做法
完全不做 VLAN，用**两根网线**：
1. 主网关 **网口1** → MT6000 **2.5G WAN**
2. MT6000 **2.5G LAN** → 主网关 **网口3**（做内网回灌）
3. 主网关的桥接 WAN 只绑网口1；网口3 留给内网；下行光口自动跟着内网走

### 优点
- **比方案 B 简单一个数量级**，不用碰 802.1Q
- 效果和方案 B 几乎一样

### 前提
弱电箱（光猫位置）到 MT6000 之间**有两根网线**，或者能再穿一根。

> **如果条件允许，我强烈建议选 B-简。** 方案 B 的单线复用是为了"只有一根线"的无奈场景，多余复杂度就是多余故障点。

## C 方案：旁路由（只为 DDNS / 代理）

### 做法
光猫**保持路由模式不动**，MT6000 关 DHCP，LAN 口接光猫 LAN 口，当旁路网关。

### 优点
- **完全不碰光猫**，零风险，随时拔线恢复
- 适合"我只想要 MT6000 的 AdGuard / 代理 / DDNS 功能"

### 缺点
- 公网 IP 在光猫手上 → 端口映射要在光猫做，而且**可能做不了**（很多移动光猫的端口映射功能被锁定/受限）
- 双层 NAT，NAT 类型变差（对游戏联机、P2P 不利）
- MT6000 不算真正的网关，只能靠 DHCP 下发网关地址来"劫持"流量

### 什么时候选它
如果你**只是想有个稳定 DDNS 域名指向家里**，且移动给了公网 IP，方案 C 最省事。
但如果你要"家庭宽带作为完整网络出口"（跑服务、开端口、做代理出口），**必须选 B**。

## 决策树（照着走）

```
问题1：家里到每个房间有网线吗？
├─ 有网线 → 可能根本不需要 FTTR 光纤，方案 A 就够（但先确认 K156-20 是否已装好）
└─ 没网线，靠 FTTR 光纤穿墙
     └─ 必须保 K156-20 → 只能 B / B-简 / C

问题2：光猫到 MT6000 之间有几根网线可走？
├─ 2 根以上 → 【B-简】双线回灌  ★最省心
├─ 只有 1 根  → 【B】VLAN 单线复用
└─ 0 根（MT6000 要放别的房间）→ 先解决布线，再回来

问题3：你的核心目的是什么？
├─ "我要 MT6000 当主路由，全屋归它管" → B / B-简
├─ "我只要 DDNS 能从外网访问家里"     → C 旁路由 + 光猫端口映射
└─ "我要家庭宽带当代理/VPN 出口"      → B / B-简（必须 MT6000 掌握公网 IP）
```

## 我给的最终建议

**走 B-简（双线回灌）。**

理由：
1. 保住你已经付费的 FTTR 全屋光纤（三个 K156-20 是资产，不是包袱）
2. 避免 VLAN 配置这一层额外故障面——VLAN 配错的表现是"全家能连 Wi-Fi 但上不了网"，非常难排查
3. 公网 IP、NAT、DDNS、端口映射全部收敛在 MT6000 一处
4. 双 2.5G 口正好用满：一个进宽带，一个回内网

如果你家确实只有一根网线，再用方案 B 的 VLAN 手法（`03-方案B详细操作步骤.md` 里两种都写了）。
