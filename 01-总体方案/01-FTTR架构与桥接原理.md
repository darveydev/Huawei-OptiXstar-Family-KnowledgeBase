# 原理篇：为什么不能"把所有光网关都改成桥接"

## 1. 你的设备到底是什么东西

先把三个概念分清，不然后面全是空的。

| 设备 | 角色 | 上行方式 | 出厂工作模式 |
|---|---|---|---|
| **V176-20** | FTTR **主网关** | 上行光口 → 接移动 OLT（局端） | **路由模式**（PPPoE 拨号 + NAT + DHCP + Wi-Fi） |
| **K156-20** ×3 | FTTR **从网关** | 上行光口 → 接 V176-20 的**下行光口** | **桥接模式**（出厂就是桥接，且**不能**单独上网） |

关键认知：**K156-20 已经是桥接模式了**，你说的"改成全部桥接"，实际上是"让主网关也桥接"。

---

## 2. FTTR 的光口是"上下两个方向"，不是普通网口

这是整个问题的核心。普通光猫只有**一个上联光口**（接运营商的），而 FTTR 主网关有**两个光口**：

```
                   ┌─────────────────────────────────┐
                   │        V176-20 主网关            │
   移动 OLT        │                                 │
   局端机房  ──────►│ 上联光口       下行光口（FTTR口）│──────┬──► K156-20 #1  (GPON)
   (XGPON)         │  (WAN侧)         (LAN侧)         │      ├──► K156-20 #2
                   │                                 │      └──► K156-20 #3
                   │  以太网口 1 2 3 4               │      （中间可串 1:4 分光器）
                   └─────────────────────────────────┘
```

- **上联光口**：面向运营商，XGPON 协议，承载你的宽带业务（VLAN 示例值（原文示例为 41） 之类）。
- **下行光口（FTTR 口）**：面向家里，GPON 协议，**由主网关自己当"小局端"（OLT 角色）**，给三个 K156-20 发号。
- 三个 K156-20 之间是**并联在分光器上**的，不是串联。它们**不认识运营商**，只认识主网关。

**这就是为什么"全部桥接"是伪命题**：K156-20 的上行是主网关的下行光口，主网关一旦不干"小局端"的活，这三个从网关就**没有任何东西可以连**。

---

## 3. 主网关切成桥接以后，会失去什么

| 功能 | 路由模式 | 桥接模式 |
|---|---|---|
| PPPoE 拨号 | 光猫自己拨 | ❌ 交给下游 MT6000 |
| NAT / 防火墙 | 光猫做 | ❌ 交给 MT6000 |
| DHCP 服务器 | 开 | ❌ 关闭（需要下游给） |
| **下行光口带 K156-20** | ✅ 正常工作 | ⚠️ **取决于配置**，默认行为是断的 |
| **主网关自身 Wi-Fi** | ✅ 能上网 | ❌ 拿不到 IP，连上也上不了网 |
| K156-20 的 Wi-Fi 和网口 | ✅ 作为 AP 工作 | ❌ 变成砖（主网关不喂它） |
| 光猫管理页面 | 同网段可访问 | 需要手动设静态 IP 或用 VLAN 隔离 |

**所以"全桥接"的真实后果**：MT6000 拨号成功，家里 Wi-Fi 只剩 MT6000 一台，三个 K156-20 全部失效，光纤白拉了。

---

## 4. 那为什么网上又说"桥接后 FTTR 还能用"

因为**有 VLAN 手法**。这是本篇最重要的原理，看懂这一段，第 3 章的操作你就全明白了。

### 4.1 桥接的本质是"光口 ↔ 网口的二层透传"

主网关改桥接，做的事是：

```
上联光口（带 VLAN 示例值（原文示例为 41） 的宽带报文）  ══二层透传══►  绑定的 LAN 口 / FTTR 下行光口
```

也就是说：**桥接后的主网关退化成一台"光转电的二层交换机"**。它不再发 IP，但报文还能穿过去。

### 4.2 单线复用：一条网线同时跑"宽带"和"内网"

MT6000 只有一个 2.5G WAN 口和一个 2.5G LAN 口（第二个 2.5G 口可切 WAN/LAN），家里如果只有一根网线通到光猫，就用 **VLAN 打标签**在同一条线上跑两路：

```
                    ┌──────────────── 一条网线 ────────────────┐
                    │                                          │
   ┌────────────────┴──┐                            ┌──────────┴────────────┐
   │   V176-20 主网关   │                            │     GL-MT6000         │
   │                   │                            │                       │
   │ 上联光口 ◄─ 移动    │                            │  WAN(2.5G) 接口        │
   │                   │    ┌─ VLAN 示例值（原文示例为 41） (tagged) ──► │   → eth.wan.41        │
   │ 桥接WAN绑定VLAN41 ─┼────┤                      │      PPPoE 拨号        │
   │                   │    └─ VLAN 1  (untagged)──► │   → br-lan (内网)      │
   │ 以太网口 2 (trunk) │                            │                       │
   │                   │                            │  2.5G LAN ──► 交换机/AP │
   │ 以太网口 1/3/4 ◄───┼── 回灌内网（见下）           │                       │
   └────────────────┬──┘                            └───────────────────────┘
                    │
                    │ 下行光口（GPON）
                    ▼
        ┌───────────┴───────────┐
        │  1:4 分光器 (可选)      │
        └──┬────────┬────────┬──┘
           ▼        ▼        ▼
       K156-20  K156-20  K156-20      ← 它们的上行是主网关，主网关是"小局端"
```

关键点：**主网关的下行光口相当于一个"内网交换口"**——只要主网关的桥接 WAN 不绑定下行光口，下行光口就归"内网"用。此时：

- MT6000 拨号拿到公网 IP，做 DHCP + NAT
- MT6000 的内网通过 VLAN 1 送回主网关
- 主网关把内网分发给 3 个 K156-20
- K156-20 当纯 AP 用，全屋漫游照旧

这就是方案 B。**它要求单线复用或第二根网线**，两者选一。

---

## 5. 三个方案的本质区别（一句话版）

| 方案 | 一句话 | 保住 K156-20？ | 需要 VLAN？ |
|---|---|---|---|
| **A 纯桥接** | 弃掉 FTTR，MT6000 独挑全屋 | ❌ 断 | 否 |
| **B VLAN 复用** | 主网关退化成二层交换机，从网关当 AP | ✅ 保 | **是** |
| **C 旁路由** | 主网关不动，MT6000 挂在旁边只做代理/DDNS | ✅ 保 | 否 |

> 方案 C 的补充说明：光猫保持路由模式，MT6000 关 DHCP 接光猫 LAN 口当旁路网关。
> 好处是零风险、随时可退；坏处是**公网 IP 在光猫手上**，端口映射要在光猫做，且流量走两次 NAT。
> 如果你**主要目的是 DDNS 出口**而非"我就要 MT6000 拨号"，方案 C 其实最省事。详见 `02-方案对比与选型.md`。

## 6. 一张图记住因果链

```
主网关桥接
   ├─ WAN侧（上联光口 + 绑定VLAN41的网口）  → 交给 MT6000 拨号
   └─ LAN侧（未绑定的网口 + 下行光口）      → 需要"别人"发 IP（MT6000 回灌）

如果 LAN 侧没人发 IP：
   ├─ 主网关 Wi-Fi 连上 = 拿不到地址，上不了网
   └─ K156-20 光口连上 = 也拿不到地址，等于砖

所以桥接后必须做的一件事：把 MT6000 的内网引回主网关的 LAN 侧
   ├─ 方式一：第二根网线（主网关网口3 ↔ MT6000 LAN）  ← 最简单
   └─ 方式二：VLAN 单线复用（VLAN1 untagged + VLAN41 tagged）← 只一根线也行
```
