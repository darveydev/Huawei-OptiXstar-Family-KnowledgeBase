# 回滚手册 —— 出问题怎么救

> **打印这一页，改造时放手边。** 每一步都有对应的撤回动作。

---

## 0. 通用急救三件套

### 急救A：全家断网，什么都上不了

```
1. 把 MT6000 的 WAN 线拔掉，插回光猫任意 LAN 口（网口2）
2. 用手机连光猫 Wi-Fi（或用网线接光猫）
3. 如果能上网 → 说明光猫还是路由模式，问题在 MT6000 → 查 MT6000
4. 如果上不了网 → 说明光猫已桥接，且没有设备在拨号 → 见急救B
```

### 急救B：光猫已桥接，家里完全没网

**方案1：笔记本临时拨号（最快恢复上网）**
```
1. 笔记本用网线接光猫"网口1"
2. Windows：设置 → 网络 → 拨号 → 新建连接 → PPPoE → 填账号密码
   macOS：系统设置 → 网络 → 添加 → PPPoE
3. 拨上就有网了（笔记本独占，其他设备还是没有）
```

**方案2：撤回桥接（恢复原状）**
```
1. 笔记本接光猫网口2
2. 网卡设静态 IP：192.168.1.10 / 255.255.255.0（如果光猫是 192.168.1.1）
   或 192.168.100.10（如果光猫是 192.168.100.1）
3. 浏览器进光猫后台
4. 网络 → 宽带设置 → 把桥接连接改回"路由" + 填上账号密码 + 勾选 NAT + 勾选 DHCP
5. 保存重启
```

**方案3：光猫恢复出厂（最后手段）**
```
⚠️ 会丢失所有配置，可能需要重新注册（LOID/Password）
1. 找光猫背面/侧面的复位孔
2. 牙签按住 10~15 秒，等所有指示灯闪一遍
3. 等它自己重新注册（移动光猫一般会自动下发配置）
4. 如果注册不上 → 打 10086 报修，说"光猫恢复出厂了，需要重新注册"
```

> **⚠️ 方案3 的代价**：移动后台重新下发配置后，你的桥接设置全部消失，等于回到起点。
> **只在方案1、2 都不行时用。**

## 1. 分步回滚表

| 你做了哪一步 | 怎么撤回 |
|---|---|
| 改了光猫桥接 | 光猫后台 → 网络 → 宽带设置 → 桥接改回路由，填账号密码，勾 NAT/DHCP |
| 关了光猫 DHCP | 光猫后台 → 网络 → LAN 设置 → DHCP 使能 ✅ 勾上 |
| 改了光猫管理 IP | 光猫后台 → 网络 → LAN 设置 → 改回原值（或用静态 IP 进后台改） |
| 插了网线A/B | 直接拔掉，插回原位 |
| MT6000 设了 PPPoE | MT6000 → 网络 → WAN → 改回 DHCP（自动获取） |
| MT6000 切了 2.5G 口为 LAN | MT6000 → 网络 → 端口 → 切回 WAN |
| 配了 DDNS | MT6000 → 应用程序 → DDNS → 关闭 |
| 配了端口转发 | MT6000 → 防火墙 → 端口转发 → 删除对应规则 |
| 改了 Wi-Fi SSID/密码 | 光猫和 MT6000 各自改回原值 |

## 2. 特殊情况处理

### 2.1 移动后台把我的桥接改回去了（很常见）

**现象**：用了几天/几周，突然断网。进光猫一看，桥接连接又变成路由模式了。

**原因**：光猫的 TR-069（远程管理协议）会定期从移动 ACS 服务器拉配置。你的手工修改被覆盖。

**处理**：
```
① 立刻确认：光猫后台看 INTERNET 连接是不是又变"路由"了
② 如果变了 → 重新改桥接（步骤同 03 第2步）
③ 想长治久安 → 关闭 TR-069：
     管理 → TR-069 → 取消"启用" → 保存
   ⚠️ 风险：关了以后移动无法远程诊断，报修时师傅可能需要你打开，
      而且有些地区关闭 TR-069 会导致无法注册/断网，谨慎
④ 或者接受这个现实，改用"方案 C 旁路由"（不动光猫，永不被覆盖）
```

> **实话**：移动对桥接用户确实有"重置"行为（多地网友反馈）。如果反复被改，说明这个地区策略严格，方案 C（旁路由）虽然慢一点但稳定。

### 2.2 拨号报错对照表

| 错误码 | 含义 | 处理 |
|---|---|---|
| **678 / 651** | 无法建立连接（线路层） | 光猫桥接 VLAN 模式错（应"改写"）或 VLAN ID 错 |
| **691** | 用户名密码错 | 核对账号后缀（如 `@139.gd`）；试 MAC 克隆 |
| **815** | 服务器无响应 | VLAN 不通 / 光猫未正确桥接 |
| **769** | 找不到网卡 | 网线没插好 / 网卡禁用 |
| **619 / 629** | 端口被关闭 | 换网口试 |
| **720** | PPPoE 协议错误 | 重启光猫 + 电脑重试 |

### 2.3 从网关（K156-20）全部红灯

| 原因 | 排查 |
|---|---|
| 主网关下行光口被绑给了 WAN | 光猫后台 → 桥接 WAN → 取消"下行光口/FTTR"绑定 |
| 内网没回灌 | 检查网线B 是否接好、MT6000 第二个 2.5G 口是否切成 LAN |
| 光猫网口3 未划入内网 | 网络 → LAN 口多业务 → 勾选网口3 + FTTR |
| 分光器/光纤问题 | 拔插光纤，检查端面清洁（⚠️ 别用手摸） |
| 光功率不足 | 主网关后台看光功率（应在 -25 ~ -8 dBm） |

### 2.4 MT6000 拨上了但内网上不了网

| 原因 | 排查 |
|---|---|
| MT6000 LAN 侧 DHCP 没开 | 网络 → 接口 → lan → DHCP 启用 |
| 光猫 DHCP 没关，两边抢着发 | 光猫 → LAN 设置 → DHCP 关闭 |
| 光猫 LAN IP 和 MT6000 同段冲突 | 光猫改 192.168.8.2，MT6000 是 192.168.8.1 |
| 防火墙 wan→lan 转发被拒 | 检查 MT6000 防火墙 forward 策略 |

### 2.5 Wi-Fi 能连但没网、漫游总掉线

| 原因 | 排查 |
|---|---|
| 加密方式不一致（一边 WPA2 一边 WPA3） | 统一为 WPA2-PSK |
| 信道重叠 | 主网关和 MT6000 信道错开 |
| 开了 802.11r 跨品牌混用 | 关掉 802.11r |
| 5G 频宽 160MHz | 改为 80MHz |
| 主网关 Wi-Fi 和从网关不同步 | 改主网关后等 3~5 分钟让从网关同步 |

## 3. 一切重来：完整复位流程

如果想彻底回到出厂状态：

```
1. MT6000：按住 Reset 10 秒 → 恢复出厂
2. V176-20 主网关：复位孔按住 15 秒 → 恢复出厂
   ⚠️ 恢复后可能需要在移动后台重新注册，或打 10086
3. K156-20 ×3：复位孔按住 10 秒 → 恢复出厂
4. 全部重新上电，等 5 分钟自动组网
5. 光猫重新拨号后，等移动后台下发配置（约 10~30 分钟）
6. 如果 30 分钟还不行 → 打 10086 说"光猫恢复出厂，需要重新下发配置"
```

## 4. 什么时候该果断放弃

出现以下情况，**别硬扛，回退到方案 C 旁路由**：

- [ ] 移动后台连续 2 次把我的桥接配置改回去
- [ ] 改了桥接后从网关连续 3 次全红，且排查不到原因
- [ ] 光猫固件里找不到"LAN 口多业务"或"VLAN 绑定"页面（硬件不支持单线复用，而你又只有一根线）
- [ ] 打了 3 个电话仍拿不到超级密码

**方案 C（旁路由）虽然不是最优解，但它 100% 可行、零风险、随时可退。**
有时候"能用的次优方案"比"完美的失败"强得多。
