# 验收测试清单

> 改造完成后，逐条打勾。任何一条不过，回去查对应章节。

## A. 拨号与出口（最关键）

- [ ] **A1** MT6000 后台 WAN 状态显示"已连接"，PPPoE 拿到 IP
- [ ] **A2** WAN IP 是公网段（不是 10.x / 100.64-127.x / 172.16-31.x / 192.168.x）
- [ ] **A3** 接 MT6000 的电脑执行 `curl https://myip.ipip.net`，返回的 IP **等于** WAN IP
- [ ] **A4** 显示归属地正确（中国 山东 xx 移动）
- [ ] **A5** 测速达到宽带标称的 80% 以上

```bash
# A2/A3 命令
ifstatus wan | grep address
curl -s https://myip.ipip.net
```

## C. 内网互通（跨 AP 访问）

- [ ] **C1** 手机连客厅 AP，能访问接在卧室 AP 上的 NAS
- [ ] **C2** 手机连卧室 AP，能访问接在 MT6000 上的电脑
- [ ] **C3** 所有设备能互相 ping 通
- [ ] **C4** 投屏/打印机/智能家居在跨 AP 场景下正常工作（如果有 AP 隔离会失败）

## D. 漫游质量

- [ ] **D1** 从客厅走到卧室，Wi-Fi 不掉线
- [ ] **D2** 切换过程 ping 丢失 ≤ 3 个包
- [ ] **D3** 视频通话/在线会议切换时不断流
- [ ] **D4** SSID 全程不变（不需要手动重连）

```bash
# Windows 长时间 ping + 观察切换
ping -t 192.168.8.1
# 另开一个窗口看当前 AP 的 BSSID
netsh wlan show interfaces | grep -i bssid
```
```bash
# macOS
ping 192.168.8.1
/System/Library/PrivateFrameworks/Apple80211.framework/Versions/Current/Resources/airport -I | grep BSSID
```

## E. 光猫管理可达

- [ ] **E1** 内网设备能访问光猫后台（如 http://192.168.8.2）

## F. 公网访问（拿到公网 IP 后才测）

- [ ] **F1** DDNS 域名能解析（`nslookup home.你的域名.com`）
- [ ] **F2** 解析出来的 IP = 当前 WAN IP
- [ ] **F3** 从**手机流量**（关 Wi-Fi）能访问到家里服务
- [ ] **F4** 从**公司/外部网络**也能访问
- [ ] **F5** IP 变化后 DDNS 能自动更新（可以手动重拨一次验证）

```bash
# F1/F2
nslookup home.你的域名.com 223.5.5.5
# F3 测试（手机浏览器）
http://home.你的域名.com:8443
# F5 触发重拨后等 5 分钟再查
```
