# GL-MT6000 配置清单（照抄版）

> 设备：GL.iNet GL-MT6000 (Flint 2)，OpenWrt 系，双 2.5G 口
> 目标：PPPoE 拨号 + DHCP + DDNS + 端口转发 + 安全加固
> 前提：已完成 `03-方案B详细操作步骤.md` 的光猫桥接

---

## 1. 端口规划

| 物理口 | 用途 | 设置 |
|---|---|---|
| **2.5G WAN** | 接光猫网口1，PPPoE 拨号 | 出厂即 WAN |
| **2.5G WAN/LAN** | **切成 LAN**，接光猫网口3 做内网回灌 | ⚠️ 必须手动切 |
| 1G LAN ×4 | 有线设备 | 默认 LAN |
| USB 3.0 | 存储/4G网卡 | 可选 |

### 1.1 切换第二个 2.5G 口为 LAN

```
GL.iNet 后台 → 网络 → 端口（Port）
  └─ 找到 "2.5G WAN/LAN" 那一行
       └─ 模式：WAN → 改为 LAN
       应用（会短暂断网重连）
```

命令行确认：
```bash
# 查看接口映射
ip link show | grep -E "^(2|3|4|5):"
# MT6000 典型：eth0=2.5G LAN, eth1=2.5G WAN
uci show network | grep -E "ports|device"
```

## 2. 基础网络设置

### 2.1 后台入口

```
http://192.168.8.1     ← GL.iNet 官方界面
http://192.168.8.1/cgi-bin/luci  ← LuCI 高级界面
```
首次登录要设管理密码。**设一个强密码，记到密码管理器。**

### 2.2 WAN（PPPoE 拨号）

```
网络 → 接口 → wan → 编辑
  协议：PPPoE
  用户名：<宽带账号>
  密码：<宽带密码>
  服务名：留空
  MTU：1492
  DNS：留空（用运营商下发），或手填 223.5.5.5 / 119.29.29.29
  IPv6：启用（DHCPv6 客户端）
```

命令行：
```bash
uci set network.wan.proto='pppoe'
uci set network.wan.username='你的账号'
uci set network.wan.password='你的密码'
uci set network.wan.mtu='1492'
uci set network.wan.ipv6='1'
uci set network.wan.peerdns='1'
uci commit network
/etc/init.d/network restart
```

验证：
```bash
ifstatus wan | grep -E '"address"|"up"'
# 期望："up": true，且有公网 address
```

### 2.3 LAN 与 DHCP

```
网络 → 接口 → lan
  IPv4 地址：192.168.8.1
  子网掩码：255.255.255.0
  DHCP：启用
  起始：192.168.8.100
  结束：192.168.8.249
  租期：12h
```

```bash
uci set network.lan.ipaddr='192.168.8.1'
uci set dhcp.lan.start='100'
uci set dhcp.lan.limit='150'
uci set dhcp.lan.leasetime='12h'
uci commit
```

### 2.4 DNS

```
网络 → DNS
  └─ 自定义 DNS：223.5.5.5, 119.29.29.29（阿里 + 腾讯）
     （或留空用运营商下发，但运营商的 DNS 可能有劫持）
```

> 如果之前配过 AdGuard Home / 自建 DNS，确认它监听在 192.168.8.1:53 并把 DHCP 的 DNS 指过去。

## 3. Wi-Fi 设置（与光猫统一，实现漫游）

```
网络 → 无线
  2.4G：
    SSID：Home-2.4G
    加密：WPA2-PSK（或 WPA2/WPA3 混合，必须和光猫一致）
    密码：<与光猫相同>
    信道：1 或 6 或 11（和光猫错开）
    频宽：20MHz
  5G：
    SSID：Home-5G
    加密：同上
    信道：149 或 157（和光猫错开，避开 DFS 信道）
    频宽：80MHz（不要 160，覆盖差且漫游不稳）
    802.11k/v：启用
    802.11r：⚠️ 关闭
```

### 3.1 信道规划表（四台设备）

| 设备 | 2.4G 信道 | 5G 信道 |
|---|---|---|
| V176-20 主网关 | 1 | 36 |
| K156-20 #1 | 6 | 44 |
| K156-20 #2 | 11 | 149 |
| K156-20 #3 | 1 | 157 |
| **MT6000** | 6 | 36 或 44（挑最空的） |

> K156-20 的信道由主网关统一下发，不能单独设。所以实际能控制的只有主网关和 MT6000 两处。
> **关键：让 MT6000 和主网关的信道错开即可。**

```
应用程序 → DDNS → 启用
```

## 5. 端口转发

```
网络 → 防火墙 → 端口转发 → 添加
```

### 5.1 常用映射（按需开，不要全开）

| 名称 | 外部端口 | 内部 IP | 内部端口 | 协议 |
|---|---|---|---|---|
| SSH-外网 | 2222 | 192.168.8.1 | 22 | TCP |
| WireGuard | 51820 | 192.168.8.1 | 51820 | UDP |
| NAS-Web | 8443 | 192.168.8.100 | 443 | TCP |
| NAS-管理 | 15000 | 192.168.8.100 | 5000 | TCP |

### 5.2 命令行批量（示例）

```bash
# SSH
uci add firewall redirect
uci set firewall.@redirect[-1]='redirect'
uci set firewall.@redirect[-1].name='SSH-WAN'
uci set firewall.@redirect[-1].target='DNAT'
uci set firewall.@redirect[-1].src='wan'
uci set firewall.@redirect[-1].dest='lan'
uci set firewall.@redirect[-1].proto='tcp'
uci set firewall.@redirect[-1].src_dport='2222'
uci set firewall.@redirect[-1].dest_ip='192.168.8.1'
uci set firewall.@redirect[-1].dest_port='22'

# WireGuard
uci add firewall redirect
uci set firewall.@redirect[-1]='redirect'
uci set firewall.@redirect[-1].name='WG'
uci set firewall.@redirect[-1].target='DNAT'
uci set firewall.@redirect[-1].src='wan'
uci set firewall.@redirect[-1].dest='lan'
uci set firewall.@redirect[-1].proto='udp'
uci set firewall.@redirect[-1].src_dport='51820'
uci set firewall.@redirect[-1].dest_ip='192.168.8.1'
uci set firewall.@redirect[-1].dest_port='51820'

uci commit firewall
/etc/init.d/firewall restart
```

### 5.3 验证端口是否通

```bash
# 从外网（手机开热点给笔记本，或手机浏览器）
nmap -p 2222 home.你的域名.com
# 或
nc -zv home.你的域名.com 2222
```

> 打不开先排查：① 移动是否封了这个端口 ② 光猫是否还有 NAT ③ 防火墙规则是否生效 ④ DDNS 是否正确

## 6. 动态 DNS + 端口自动更新脚本（可选增强）

IP 变了端口映射不用改（映射是按域名无所谓），但如果你有外部服务需要知道 IP，可以加个脚本：

```bash
cat > /etc/hotplug.d/iface/99-ddns-notify <<'EOF'
#!/bin/sh
[ "$ACTION" = "ifup" ] && [ "$INTERFACE" = "wan" ] || exit 0
IP=$(curl -s --max-time 10 https://api.ipify.org)
logger -t ddns "WAN up, public IP: $IP"
# 可选：推送到你的通知渠道
EOF
chmod +x /etc/hotplug.d/iface/99-ddns-notify
```

## 7. 安全加固（暴露公网必做）

### 7.1 关闭 UPnP

```
网络 → 防火墙 → 常规设置 → UPnP：❌ 关闭
```
```bash
uci set upnpd.config.enabled='0'
uci commit upnpd
/etc/init.d/miniupnpd stop 2>/dev/null
/etc/init.d/miniupnpd disable 2>/dev/null
```

### 7.2 SSH 加固

```bash
# 改端口 + 关密码登录（先确保公钥已配置！）
uci set dropbear.@dropbear[0].Port='2222'
uci set dropbear.@dropbear[0].PasswordAuth='off'
uci set dropbear.@dropbear[0].RootPasswordAuth='off'
uci commit dropbear
/etc/init.d/dropbear restart
```

**配公钥（在关密码登录前做）：**
```bash
# 在你自己的电脑上
ssh-keygen -t ed25519 -C "mt6000"
cat ~/.ssh/id_ed25519.pub
# 复制输出，粘到 MT6000 的 /etc/dropbear/authorized_keys
```

### 7.3 防火墙默认策略确认

```
网络 → 防火墙 → 常规设置
  wan 区域：
    Input：❌ 拒绝（默认就是，别改成接受）
    Output：接受
    Forward：拒绝
    伪装（Masquerade）：✅ 开启
```

### 7.4 关闭不必要的服务

```bash
# 看开了哪些
netstat -lntup

# 关闭不用的
/etc/init.d/uhttpd  # 别关，这是 LuCI
/etc/init.d/ttyd disable    # 如果不用网页终端
```

## 8. MT6000 特有注意点（实测坑）

| 坑 | 说明 |
|---|---|
| **GL.iNet 2.5.5+ 的"应用设置"会硬覆盖全局扩展** | 改了 LuCI 的 DNS/防火墙，可能被 GL 自己的配置覆盖。改完要在 GL 界面确认一遍 |
| **官方固件的 VLAN 支持弱** | 单线复用方案建议用 LuCI 或 SSH，别指望官方界面 |
| **双 2.5G 口默认都是 WAN 候选** | 回灌必须手动把第二个切成 LAN |
| **8GB eMMC 可以装很多插件** | 但别装太重，Opkg 空间够用就好 |
| **USB 3.0 可能干扰 2.4G Wi-Fi** | 用 USB 3.0 设备时把 2.4G 信道避开干扰 |
| **固件升级会重置部分配置** | 升级前 `uci export > /etc/config-backup.txt` 备份 |
| **散热** | 高负载（大量 NAT + VPN）会热，别放在密闭柜里 |
