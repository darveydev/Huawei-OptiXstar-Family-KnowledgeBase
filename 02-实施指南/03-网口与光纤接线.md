### 2.1 接线清单（照着插）

| # | 从 | 到 | 线材 | 说明 |
|---|---|---|---|---|
| A | V176-20 **网口1** | MT6000 **2.5G WAN** | 超五类/六类网线 | 宽带业务出口（VLAN 示例值（原文示例为 41） 透传） |
| B | MT6000 **2.5G LAN** | V176-20 **网口3** | 超五类/六类网线 | 内网回灌，让 K156-20 活过来 |
| C | 入户光纤 | V176-20 **上联光口** | 原有 SC/APC | 别动 |
| D×3 | V176-20 **下行光口**（经分光器） | K156-20 **上联光口** ×3 | 原有透明光纤 | 别动 |
| E | MT6000 1G LAN | 交换机/NAS/台式机 | 任意 | 看需求 |
| F | 电源 | 三台光网关 + MT6000 | 原装适配器 | 别用杂牌 |

### 2.2 MT6000 网口物理布局（Flint 2）

面朝背面（从左到右）：

```
┌────────────────────────────────────────────────────────────────┐
│  Reset  │  DC12V  │ 2.5G WAN │ 2.5G WAN/LAN │ 1G │ 1G │ 1G │ 1G │ USB │
└────────────────────────────────────────────────────────────────┘
              ▲          ▲              ▲
              │          │              └── 网线B 插这里（须先在后台切成 LAN）
              │          └── 网线A 插这里（WAN，PPPoE）
              └── 电源
```

⚠️ **第二个 2.5G 口出厂可能是 WAN 模式**，必须在后台 `网络 → 接口` 里把它设为 **LAN**，否则网线B 起不到回灌作用。

## 3. 方案 B 单线复用的接线（只有一根网线时）

```
        V176-20                           GL-MT6000
   ┌─────────────┐  一根网线（trunk）   ┌─────────────┐
   │  网口1 ●════╪═══════════════════╪═══● 2.5G WAN │
   │  (trunk)    │                    │             │
   │             │                    │ eth1.41 → PPPoE
   │  下行光口 ●─┼──光纤──► K156 ×3    │ eth1    → br-lan
   │  网口3 ● 空  │                    │             │
   └─────────────┘                    └─────────────┘
        ▲
        └─ VLAN41 tagged（给 MT6000 拨号）
           VLAN1  untagged（MT6000 内网回灌）
           同一根线里共存
```

这根线上跑两种帧，互不干扰。配置见 `03B-单线复用VLAN配置.md`。

## 4. 光纤部分：千万别动

| 光纤 | 接头类型 | 能不能拔 | 说明 |
|---|---|---|---|
| 入户光纤 → 主网关 上联光口 | SC/APC（绿头） | **不建议拔** | 拔了要重新对角度，容易脏 |
| 主网关 下行光口 → 分光器 | SC/APC | 可以，但没必要 | 改造全程不需要动 |
| 分光器 → K156-20 | SC/APC | 可以 | 只有在排查从网关故障时才拔 |

**光纤三条禁忌：**
1. ❌ **绝对不能弯折超过半径 3cm**，一折就断，断了要重新熔接（花钱请人）
2. ❌ **不能直视光纤端面**（激光伤眼，虽然家用功率低，但别试）
3. ❌ **端面不能摸、不能沾灰**，脏了用无水酒精 + 无尘纸单向擦，或换新的

> **改造全程你的手只需要碰网线，不需要碰光纤。** 如果某一步的说明让你拔光纤，那就是方案搞错了。

## 5. 分光器在哪？找不到怎么办

你的三个 K156-20 通过光纤连主网关，中间大概率有一个 **1:4 分光器**（一个小方盒，有 1 个进 4 个出，通常塞在弱电箱或天花板检修口）。

- **找不到也没关系**：改造不需要动它
- 想确认连接关系：看主网关下行光口出来的那根光纤走向哪里
- V176-20 的下行光口**可能直接支持多路**（部分型号内部集成了分光），也可能必须外接分光器

## 6. 改造前后对比速记

| 项目 | 改造前 | 改造后 |
|---|---|---|
| 谁拨号 | V176-20 | **MT6000** |
| 谁发 IP | V176-20 (192.168.1.x) | **MT6000 (192.168.8.x)** |
| 谁做 NAT | V176-20 | **MT6000** |
| 公网 IP 在哪 | V176-20 | **MT6000** ← DDNS/端口映射都在这 |
| V176-20 角色 | 网关 | **二层交换机 + AP** |
| K156-20 角色 | AP | **AP（不变）** |
| 网线数量 | 0~1 | **2 根**（B-简）或 **1 根 trunk**（B） |
| 光猫 Wi-Fi | 能上网 | 能上网（走 MT6000 的 DHCP） |
