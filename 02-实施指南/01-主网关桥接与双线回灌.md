## 第 1 步：先验证宽带账号是好的（不改任何配置）

在动手之前，用笔记本直接拨号验证账号有效：

1. 笔记本用网线接光猫 **网口2**（此时光猫还是路由模式，网口2 在 LAN 侧）
2. ⚠️ 这一步在路由模式下**不能**直接拨号成功（光猫已经拨了），所以真正验证要等桥接后。
   **替代验证**：光猫后台 → 状态 → 看 WAN 连接的 PPPoE 用户名，确认它显示了完整账号。
3. 如果光猫后台的 PPPoE 用户名被星号隐藏，试试浏览器 F12 查看 value。

> 拿不到密码的话，这里就是最后的止损点。**宁可放弃改造，也不要盲改。**

## 第 2 步：改 V176-20 主网关为桥接（核心步骤）

### 2.1 登录

浏览器打开光猫管理地址 → 用超级管理员账号登录。

### 2.2 找到原上网连接

路径（不同固件略有差异）：
```
网络 → 宽带设置 → 选中"连接名称"下拉里的 INTERNET 那条（名字类似 2_INTERNET_R_VID_41）
```

记下这条的：**VLAN ID、802.1p、业务类型、IP 模式、用户名、密码**。

### 2.3 改成桥接（两种改法，选一种）

#### 改法一：就地改（推荐，保留 VLAN 参数最省事）

在原 INTERNET 连接上直接改：

| 参数 | 改成 |
|---|---|
| 连接模式 / 封装类型 | **PPPoE → 桥接（Bridge）** 或 "连接模式：桥接" |
| 业务类型 | INTERNET（保持不变） |
| **VLAN 模式** | **改写（Tag）/ 改写** ← 关键，必须是 tag 不是透传 |
| **VLAN ID** | **保持原值**（移动常见 41） |
| 802.1p | 保持原值（常见 0 或 5） |
| IP 模式 | IPv4&IPv6（保持） |
| **DHCP 服务使能** | ❌ **取消勾选** |
| **NAT 使能** | ❌ **取消勾选** |
| **LAN 端口绑定** | ✅ **只勾 网口1**（方案 B-简 的第二根线走网口3；方案 B 单线也是网口1） |
| **SSID 端口绑定** | ❌ **全部取消** |
| **下行光口 / FTTR / PON 绑定** | ❌ **务必不勾**（勾了从网关就废） |

点"应用"/"保存"。

> **⚠️ 最容易错的三处：**
> 1. VLAN 模式选了"透传"而不是"改写" → MT6000 拨不上
> 2. 勾了下行光口/FTTR → 三个 K156-20 全部失效
> 3. 忘了取消 NAT → 双重 NAT，公网映射失败

#### 改法二：新建桥接 + 删掉原路由连接

1. 先"新建"一条：连接模式=桥接，VLAN 同上，绑定网口1
2. 确认新连接"已连接"状态
3. 再删掉原来那条 INTERNET 路由连接

> 改法二更干净，但如果新连接建错就没网了，风险略高。**改法一优先。**

### 2.4 关闭光猫自身的 DHCP（关键）

```
网络 → LAN 设置 → DHCP 服务器 → 取消"使能" → 保存
```

这样光猫不会和 MT6000 抢着发 IP。

### 2.5 修改光猫自身管理 IP，避免和 MT6000 冲突

```
网络 → LAN 设置 → LAN IP：
   如果 MT6000 用 192.168.8.1（GL.iNet 默认） → 光猫改成 192.168.8.2
   如果 MT6000 用 192.168.1.1              → 光猫改成 192.168.1.2
```

⚠️ 改完光猫 IP 后，你需要**手动设静态 IP** 才能再进光猫后台：
```
笔记本网卡设：IP 192.168.8.2 段内可用地址（如 192.168.8.10）
掩码 255.255.255.0，网关留空
然后浏览器访问 http://192.168.8.2
```

### 2.6 关闭 Wi-Fi 相关的冲突（可选但建议）

如果光猫和 MT6000 用同一个 SSID 会冲突：
```
网络 → WLAN → 把光猫的 SSID 名字改掉（如加后缀 _AP）
```
> 保留 Wi-Fi 功能（它还要当 AP），**只改名字**避免和 MT6000 打架。
> 更好的做法：让光猫和 K156-20 统一用**同一个 SSID + 同一个密码**，关掉加密方式差异，实现无缝漫游（见第 5 步）。

### 2.7 此时的状态

改完保存后：
- ✅ 光猫上联光口仍是通的（物理层/链路层正常）
- ✅ 桥接 WAN 从网口1 透出 VLAN 示例值（原文示例为 41） 报文
- ❌ 光猫自己不再有 IP 上网
- ❌ 光猫 Wi-Fi 和 K156-20 **暂时全部断网**（因为没人发 IP）
- ⚠️ **这是正常的**，等第 3、4 步回灌后就恢复

## 第 3 步：MT6000 拨号

### 3.1 物理连接（先做 B-简 双线方案）

```
V176-20 网口1  ────网线A────►  GL-MT6000 2.5G WAN 口
V176-20 网口3  ◄───网线B────  GL-MT6000 2.5G LAN 口（那个可切 WAN/LAN 的口）
```

⚠️ 网线B **必须**插在 MT6000 的第二个 2.5G 口（切成 LAN 模式），不要插 1G 口——回灌内网要跑满千兆。

### 3.2 MT6000 后台设置

登录 `http://192.168.8.1`（GL.iNet 默认）：

```
网络 → 接口 / Internet
  ├─ 协议：PPPoE
  ├─ 用户名：<你的宽带账号>
  ├─ 密码：<你的宽带密码>
  ├─ 服务名：留空（移动一般不需要）
  ├─ MTU：1492（PPPoE 标准）；如果某些站点打不开试 1480
  └─ 应用
```

如果拨不上，检查：
- VLAN 是否需要打 tag → 单线复用方案（方案 B）时，要在 MT6000 上建 `eth.wan.41` 虚拟接口，见第 6 章
- 账号后缀是否正确（移动有时要求 `手机号@139.gd` 之类）

### 3.3 验证拨号成功

```
MT6000 后台 → 首页 → 应显示 WAN IP = 112.38.x.x（公网段）
命令行验证（接 MT6000 的电脑）：
  curl https://myip.ipip.net
  → 显示 中国 山东 xx 移动，且和 MT6000 后台显示的 IP 一致
```

✅ 走到这里，**MT6000 已经有公网出口了**，插在 MT6000 上的设备应该能上网。

## 第 4 步：把内网回灌给光猫（让 K156-20 活过来）

**只有做了这一步，三个从网关和主网关的 Wi-Fi 才会恢复。**

原理：光猫的下行光口和未绑定的网口都在"内网侧"，需要一个 DHCP 源给它们发地址。MT6000 从网口3 灌回去就行。

### 4.1 B-简 双线方案（已在上一步接好网线B）

需要确认光猫把网口3 归到内网：

```
光猫后台 → 网络 → LAN 设置 → 网口3 勾选"使能"（LAN 侧）
         → 网络 → LAN 口多业务 → 勾选 网口3 + FTTR/下行光口（让它们同属内网）
         → 确认 桥接WAN 没有绑定网口3 和 下行光口
```

保存后，等 1~2 分钟：

- K156-20 指示灯应变**蓝灯常亮**（表示已组网且拿到 IP）
- 手机连光猫/K156-20 的 Wi-Fi → 应该能上网
- 手机上查 IP → 应该是 MT6000 的内网地址（如 192.168.8.x）
- 手机上查出口 IP → 应该是 MT6000 的 WAN IP（公网）

### 4.2 方案 B 单线复用（只有一根网线）

见下一章 `03B`，这里简述：

1. 光猫：桥接 WAN 绑定 VLAN 示例值（原文示例为 41） 到网口1（tagged）
2. 光猫：网口1 同时作为 trunk，VLAN 1 untagged 透出内网
3. MT6000：`eth.wan` 上建 802.1Q 子接口 VLAN 示例值（原文示例为 41） 给 PPPoE
4. MT6000：把 `eth.wan`（untagged）加入 `br-lan`
5. 光猫：网口3/4 与下行光口归内网

详见 `03B-单线复用VLAN配置.md`。

## 第 5 步：统一 Wi-Fi 实现无缝漫游

主网关 Wi-Fi + 3 个 K156-20 都在同一内网了，现在要让手机/笔记本**自动切换**、不掉线。

### 5.1 统一参数（三边都必须一致）

| 参数 | 值 |
|---|---|
| SSID（2.4G） | 例如 `Home-2.4G` |
| SSID（5G） | 例如 `Home-5G` |
| 密码 | 同一个复杂密码 |
| 加密方式 | WPA2-PSK / WPA2/WPA3 混合（**不要一边 WPA2 一边 WPA3**） |
| 频宽（5G） | 80MHz（漫游更稳，160MHz 覆盖差） |
| 信道（5G） | 主网关与 K156-20 用**不同信道**（如 36 / 44 / 149 / 157） |
| 信道（2.4G） | 1 / 6 / 11 三选一，彼此错开 |
| 802.11k/v | 启用（华为默认开，无需干预） |
| 802.11r | 保持关闭（不同型号混用开 r 容易掉线） |

### 5.2 主网关侧设置

FTTR 主网关有个好处：**改主网关的 Wi-Fi，从网关会自动同步**。

```
光猫后台 → 网络 → WLAN 设置
  ├─ 2.4G SSID/密码/加密方式
  ├─ 5G   SSID/密码/加密方式
  ├─ 信道：手动指定，不要用"自动"（多AP自动选信道会互相打架）
  └─ 保存 → 等 3~5 分钟从网关同步
```

### 5.3 MT6000 侧设置

MT6000 的 Wi-Fi 也设成**同样的 SSID + 密码 + 加密方式**，但：
- **信道必须和光猫错开**
- MT6000 支持 802.11k/v，打开
- **不要开 802.11r**（跨品牌混用易翻车）

### 5.4 验证漫游

手机上装一个 Wi-Fi 分析仪 / 或用笔记本命令行：

```bash
# Windows：边走边看信号强度和 BSSID 变化
netsh wlan show interfaces
```
从客厅走到卧室，观察：
- SSID 始终不变 ✅
- BSSID（AP 的 MAC）会切换 ✅
- 切换瞬间 ping 不要丢超过 2~3 个包

## 常见故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| MT6000 拨号报 678 / 651 | 光猫桥接 VLAN 模式选错（透传 vs 改写） | 改回"改写(Tag)"，VLAN ID 核对 |
| MT6000 拨号报 691 | 账号密码错 / 账号被绑 MAC | 核对账号后缀；用原光猫的 MAC 克隆试试 |
| 拨号成功但电脑上不了网 | MT6000 DHCP 没开 / DNS 没配 | 检查 MT6000 LAN 侧 DHCP 服务器 |
| 拨号成功、MT6000 能上网，但光猫 Wi-Fi 和 K156-20 上不了 | **内网没回灌**（第 4 步没做/网线B没接/网口3没划到内网） | 重点查这根线 |
| K156-20 红灯 / 不亮蓝灯 | 主网关下行光口没归到内网，或光功率不够 | 检查"LAN口多业务"是否勾了 FTTR/下行光口 |
| 网速只有一半 | 线插在 1G 口 / 光猫网口是 1G | 换 2.5G 口；确认用超五类以上网线 |
| 一切正常，但过几天突然断网 | **移动后台重新下发配置覆盖了桥接** | 见 `07-回滚手册.md` 的"移动重置"章节 |
